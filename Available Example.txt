  - [Adjustment]

    - OffsetGain
      - The algorithm that transforms image by applying offset and gain.
      - Offset, Gain을 적용하여 이미지 변환을 수행하는 알고리즘.

  - [Channel]

    - ChannelMax
      - The example of an algorithm that extracts maximum value of each pixel from a multichannel image.
      - 다채널 이미지에서 각 픽셀의 최대값을 추출하여 이미지화 하는 알고리즘 예제.
    - ChannelMean
      - The example of an algorithm that extracts mean value of each pixel from a multichannel image.
      - 다채널 이미지에서 각 픽셀의 평균값을 추출하여 이미지화 하는 알고리즘 예제.
    - ChannelMin
      - The example of an algorithm that extracts minimum value of each pixel from a multichannel image.
      - 다채널 이미지에서 각 픽셀의 최소값을 추출하여 이미지화 하는 알고리즘 예제.
    - ChannelStdev
      - The example of an algorithm that extracts standard deviation value of each pixel from a multichannel image.
      - 다채널 이미지에서 각 픽셀의 표준편차값을 추출하여 이미지화 하는 알고리즘 예제.
    - ChannelSwap
      - The example of an algorithm that swaps two channels selected from a multichannel image.
      - 다채널 이미지에서 두개의 채널을 교환하여 이미지화하는 알고리즘 예제.
    - ChannelVariance
      - The example of an algorithm that extracts variance value of each pixel from a multichannel image.
      - 다채널 이미지에서 각 픽셀의 분산값을 추출하여 이미지화 하는 알고리즘 예제.

  - [Image Operation]
  
    - OperationComplexMultiply
      - The algorithm that performs Complex Multiply operation on the source image.
    - OperationScaledDivide
      - The algorithm that performs a Scaled Divide operation with an image or scalar value.
      - 이미지를 스칼라 또는 다른 이미지와 스케일 나눗셈 연산을 수행하는 알고리즘.
    - OperationSignedSquareDifference
      - The algorithm that perform Signed Square Difference operation an image with scalar or other image.
      - 이미지를 스칼라 또는 다른 이미지와 부호 정보가 보존된 차이의 제곱 연산을 수행하는 알고리즘.
    - OperationTrailingOnes
      - The algorithm that performs the calculation of trailing ones from the source image.
      - 이미지에 Trailing Ones 연산을 수행하는 알고리즘
